# Maison Bulléa

Démonstration de site pour une savonnerie artisanale, avec présentation de l’atelier et catalogue.

[Voir le site](https://rzu-it.github.io/maison-bullea.fr/)

![Maison Bulléa](assets/images/hero_savons_web.jpg)

HTML, CSS et JavaScript. Le catalogue présente les produits ; il ne prend pas de commandes ni de paiements.

## En local

```sh
python -m http.server 8000 --bind 127.0.0.1
```

Ouvrir http://127.0.0.1:8000/ depuis la racine du dépôt.
